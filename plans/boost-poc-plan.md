# Boost PoC – Voice Bot Use Case Plan

## Background

Based on the meeting transcription from June 17, 2026, the team agreed to build a comprehensive list of Voice Bot use cases for the Boost PoC. The use cases will cover merchant services in the Nordics and DAC regions, including:

- Smart switchboard expansion (routing & error transfer elimination)
- Terminal error code self-service
- Real-time voice translation
- Full voice bot automation (intent handling + knowledge articles)

The list should be generic enough to reuse across other platform evaluations (Genesis, Sinch, Found Ever).
